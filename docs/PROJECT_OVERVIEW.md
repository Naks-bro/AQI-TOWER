# Project Overview

## Project

AQI Tower

## Purpose

Develop and computationally investigate a tower-type air purification system before physical fabrication.

## Current Concept

The current concept is a vertical, tower-shaped machine that would move air through intake and exhaust fans and multiple treatment stages. Possible stages include a HEPA filter, a biochar or biomass-derived adsorption stage, and an experimental water-based dust-separation stage. The system is expected to use electrical power with possible solar assistance and may eventually include sensors and monitoring. Every element remains conceptual and must be tested before it is accepted.

## Team

The team is primarily composed of students from computer science and biotechnology backgrounds, so engineering explanations must remain accessible.

## Current Status

Phase 8 empty-tower geometry optimization is complete. Three parametric variants were run with the unchanged KVO 250 model. GEO_C is the promising best current geometry and a fresh confirmation reproduced its converged numerical result; it is not a final product geometry. No purification performance has been modelled or validated. See `results/GEOMETRY_OPTIMIZATION_COMPARISON.md`.

The original high-level phase list below is preserved. The continuation briefs call the real-fan study Phase 7 and the airflow-geometry optimization Phase 8; this does not silently renumber the original roadmap.

## Important Principle

Simulation should progressively validate the design rather than assuming the current concept is correct.
